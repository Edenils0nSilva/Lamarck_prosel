# Prompts

Os prompts usados durante o desenvolvimento, **na íntegra e em ordem** — como foram
escritos, não reescritos depois para ficarem bonitos.

Convenção de nome: `NNNN-descricao-curta.md`, na ordem em que foram usados.

Exemplo:

```
0001-levantamento-requisitos.md
0002-modelagem-uml.md
0003-scaffold-repositorio.md
...
```

Cada arquivo contém o prompt exatamente como enviado (e, opcionalmente, uma nota curta do
contexto em que foi usado).
